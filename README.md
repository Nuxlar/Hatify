# Hatify

Adds hats to every vanilla survivor and their modded skins except for some specific skins. Fathomless Voidling gets a hat too. Setting the config to 0 prevents the hat from being added to that survivor. No hats on these skins: Bandit (base), Bandit (alt), Bandit (modded), Chef (base), and Chef (modded)
